ESP32-S3 433MHz 智能遥控器

在线固件烧录工具 - 无需安装开发环境

设备信息

芯片型号 ESP32-S3
开发板 立创 ESP32-S3-R8N8
固件版本 v2.0.0最新
发布日期 2025-11-08

系统要求

  • Chrome 89+ 或 Edge 89+ 浏览器
  • USB 数据线（需支持数据传输）
  • Windows / macOS / Linux / ChromeOS

烧录步骤

  1. 使用 USB 数据线连接 ESP32-S3 开发板到电脑
  2. 点击下方"连接并烧录"按钮
  3. 在弹出窗口中选择对应的串口设备
  4. 等待烧录完成（约 1-2 分钟）
  5. 烧录完成后，设备会自动重启
抱歉，您的浏览器不支持 Web Serial API。
请使用 Chrome 89+ 或 Edge 89+ 浏览器。 未授权访问串口。请检查浏览器权限设置。
